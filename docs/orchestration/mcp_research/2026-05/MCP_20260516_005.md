## 근본 원인

### RC-001: Windows cp949 UnicodeEncodeError

- **위치**: `cli.py:66  click.echo("✓ Semantic Scholar API key configured")`
- **원인**: API 키가 설정되면 `✓` (U+2713)를 stdout에 출력. 한국어 Windows cp949는 U+2713 인코딩 불가.
- **결과**: MCP 서버가 stdio 핸드셰이크 직전에 즉시 crash.
- **fix**: `.mcp.json` env 블록에 `PYTHONUTF8=1`, `PYTHONIOENCODING=utf-8` 추가.

### RC-002: banner-on-stdout MCP stdio 규약 위반

- **위치**: `cli.py` lines 63, 66, 68-70, 74-78, 81-83, 104-106 (14개 `click.echo` 호출)
- **원인**: MCP stdio 규약은 stdout=JSON-RPC 전용, 사람용 로그=stderr 요구.
  현재 코드는 배너 7~10줄을 stdout에 출력하여 Claude Code JSON parser를 破괴.
- **fix**: 14개 `click.echo` 호출에 `err=True` 추가 → stderr redirect.
