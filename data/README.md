# data/

This directory is a placeholder. Datasets are generated by P2+ scripts.

**Do not commit:**
- Any `.npz`, `.pt`, `.pkl`, `.csv`, `.parquet` data files
- Screenshots or binary assets
- Any file containing private user data or secrets

Dataset generation starts at CC-P2 (text-only) and CC-P4 (synthetic GUI MVE).

**Manifest policy (14 §8, DATAOBJ-REQ-009/010):**
- Every dataset shard must pass leakage audit before being used in a training loader.
- Every export must produce a `SplitManifest` and `RunManifest` with config hash and seed.
