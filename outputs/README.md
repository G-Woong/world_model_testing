# outputs/

This directory is a placeholder. Outputs are generated by P3+ training and evaluation scripts.

**Do not commit:**
- Model checkpoints (`.pt`, `.bin`, `.safetensors`)
- Raw metric artifacts
- Any large binary file

**Manifest policy (14 §8, DATAOBJ-REQ-009/010):**
- Every run must write `outputs/runs/{run_id}/run_manifest.json` with config, seed, and status.
- Reports are generated only from real log artifacts (REPORT-REQ-006, no fake numbers).
